# TraceMind
An AI-powered assistant built with Streamlit and Ollama, leveraging local Large Language Models for intelligent question answering, summarization, sentiment analysis, and MCQ generation.
An intelligent student assistant built using **Streamlit** and **Ollama** that helps students learn faster, revise smarter, and test their knowledge using local Large Language Models (LLMs).

---

## 🚀 Features

### 📚 Q&A Assistant
- Ask questions on any topic
- Simple and easy-to-understand explanations
- Examples included for better learning

### 📝 Smart Summarizer
- Summarizes lengthy articles, notes, and reports
- Extracts important key points
- Generates concise study notes

### 😊 Sentiment Analyzer
- Detects Positive, Negative, or Neutral sentiment
- Provides confidence scores
- Gives brief reasoning

### ❓ MCQ Generator
- Generates Multiple Choice Questions
- Adjustable difficulty levels
- Includes answer key
- Useful for self-assessment

### ⚙️ Customizable AI Settings
- Multiple Ollama models
- Temperature control
- Answer length control

### 📜 History Tracking
- Saves previous interactions during session

### 📥 Download Responses
- Export AI-generated responses as text files

## ⚡ Installation

### 1. Clone Repository

```bash
git clone https://github.com/yourusername/one-percent-better.git
cd one-percent-better
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Install Ollama

Download Ollama:

https://ollama.com

### 4. Pull a Model

```bash
ollama pull gemma3:1b
```

or

```bash
ollama pull llama3.2:1b
```

### 5. Run the Application

```bash
streamlit run app.py
```
